# CMS-08D Web static adapter (historical)

This describes the former static Web integration. Episode 3 replaced its production build and runtime path; see `docs/CMS_RUNTIME_WEB.md`. The materialization workflow below is retained as historical context only.

The Web build consumes an explicit, deterministic local materialization package. It makes no CMS network calls. The input is a JSON file supplied through `CMS_PUBLICATION_INPUT`, containing the 08C materialization's `publicationCode`, `snapshotHash`, `webSha`, `technicalAsOf`, exact `cms-publication-v1` snapshot, public `assets` metadata, and public `usages` map. Verified derivative bytes are sibling files at `_cms/assets/<sha256>.<ext>` relative to the JSON file's directory. The input path and private work identity are build-only and never emitted.

`src/features/publication/publication.mjs` validates the required localized fields and public asset references, then produces the narrow Home, Service, Website Event, Gallery and Tree view models. EN is unprefixed; ES and FR use `/es` and `/fr`. Missing input fails before rendering. There is no legacy content fallback. `CMS_PUBLICATION_MODE=fixture pnpm build` explicitly selects a synthetic local fixture; tests use that mode. A publication build omits the fixture mode and must set `CMS_PUBLICATION_INPUT=/absolute/path/to/package.json`. It requires a clean Git checkout and a package `webSha` equal to HEAD. Never use fixture mode in a real release.

The existing Astro route families render the CMS model. Home retains its existing Hero, PanelReveal, editorial sections and scene behavior; the gallery archive and detail routes retain their existing visual classes and page geometry. Hero video/poster, global shell, fixed contact destinations and non-CMS pages remain Web-owned. CMS media is referenced by its materialized immutable public path, with no Astro image transformation. Tree eligibility is `ACTIVE && technicalAsOf < end`; the supplied `technicalAsOf` is the only time source. The snapshot contract includes ACTIVE CEV records only; an INACTIVE CEV is excluded upstream and the pure selector also excludes it defensively.

`pnpm build` runs Astro and `scripts/finalize-cms-publication.mjs`. The finalizer verifies and copies exact asset bytes, hashes every required CMS route's emitted HTML, rejects missing routes, and writes `dist/_cms/artifact.json`. The marker is the exact 08C `cms-static-artifact-v1` manifest plus `promotedArtifactSha256`; the marker excludes itself from the hash. Its canonicalizer is tested against 08C's fixed vector. This episode does not run the expiry scheduler or coordinate hosting promotion.
